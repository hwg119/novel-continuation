# 许可证与来源审计

更新日期：2026-10-06

本文记录当前仓库公开发布前的许可证核对结果，方便维护者和贡献者了解依据。它不是法律意见。

## 已确认事项

- 项目 README 和提交历史表明，早期实现参考了 `YILING0013/AI_NovelGenerator` 的模型适配与小说生成思路。
- 上游仓库以 GNU Affero General Public License v3.0 发布。
- 当前仓库仍保留与早期实现同名或同用途的模块，例如 `llm_adapters.py`、`embedding_adapters.py`，因此不能在缺少逐文件溯源证据时假定所有上游代码都已被完全替换。
- 为保持许可兼容并降低使用者的不确定性，当前仓库整体以 AGPL-3.0 发布，完整条款见根目录 `LICENSE`，来源说明见 `NOTICE`。
- `config.json`、`workspace/`、用户导入的小说与运行日志均被 `.gitignore` 排除，不属于仓库发行内容。
- `examples/demo-project/` 中的《雾港来信》为本项目演示用途原创虚构内容，不改编自现有小说。

## 发布与分发要求摘要

分发本项目的修改版时，应保留许可证和版权/来源通知，并向接收者提供相应源代码。若修改版通过网络向用户提供交互服务，还需遵守 AGPL 第 13 条的相应源代码提供义务。应以 `LICENSE` 原文为准。

用户自行导入或创作的小说文本不因使用本软件而自动适用 AGPL；模型供应商条款、训练数据要求及所在地法律仍需由用户自行确认。

## 尚待维护者持续核对

- 如需改用其他许可证，必须先完成逐文件来源追踪，并获得所有相关版权所有者许可。
- 发布二进制安装包前，应生成第三方依赖清单并随包附带相应许可证文本。
- 接受外部贡献时，应要求贡献者确认其有权按 AGPL-3.0 提交代码和素材。

## 维护规则

引入复制或改写的第三方代码、素材、提示词或示例数据时，应在提交中记录来源、版本、许可证与修改范围；不能确认授权的内容不得进入发行分支。

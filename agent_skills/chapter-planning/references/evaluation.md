# 规划评价的共同判断方法

先读当前版本的实际场景，再判断目标是否实现和故事能否自然推进。旧助手评价只是待复核意见，不是证据；重新评估不意味着必须推翻旧结论或找到新问题。

沿人物行动检查“信息来源 → 当时知道什么 → 作出什么选择 → 结果支持多强的结论”。传递动作成立不代表传递的判断成立；名字、姓氏、别名不能凭字串相同补齐。线索放在一起、特征相似或材料相同，只能支持怀疑或进一步查证，不自动证明身份、归属或因果。

沿跨幕顺序核对资料与物件的获知、取得及使用；尚不知道某物存在时，不提前针对它作具体计划。若人物只泛称将来寻找样本，不算提前使用。修改一个动作后，同步相关幕和已知信息、新增信息、结尾状态，不叠加互相冲突的新旧说明。

时间推进、待办转为行动、普通动作省略和自然动作衔接本身不构成冲突。不同场景已标明清晨、傍晚等时段时，不强求逐小时过渡；只有时间先后不能同时成立或影响关键因果时才指出问题。

重点找影响主线、后续写作或人物行动的真实问题，不凑细节错误。每项问题有当前版本的短原句和必要的上下文依据，说明影响及最小调整方向；不确定时说明缺口。有效的情绪、日常和静场可保留；增强建议与必须修正的问题分开。

对修订目标作整体判断，考虑必须保留的范围；示例和备选是实现方式，不强求全部采用。仅满足某个词句不足以证明目标落实，已落实部分不重写成未发生。

# 整章重写交付

依据明确要求修订完整章节，保留既定主线结果、正确情节和场景先后关系，不把原章压缩成摘要。不机械要求固定幕数；以实际大纲及正文为准。情节增强可调整相关段落的组织和篇幅，但不演变成另写一章。

先把长篇编辑意见理解成一个整体目标，而不是执行清单：守住明确的既有事实和禁止结果，具体地点、分组、步骤、道具、感官形式及示例均可按小说需要取舍、合并或替换。不要让人物通过反复声明“不能确认、不得追问、需要记录”等规则来证明合规；规则应主要体现为人物选择造成的后果。

新任务、新地点或新人物进入正文前必须有自然动机。若原稿缺少连接，补入最短的行动起因，而不是解释性制度段落。优先写一条能够持续推动人物的行动线，让关系、情绪与意外在行动中发生；不追求覆盖全部建议素材。

时间表达服务于阅读而非记录。保证事件自然向前推进，优先使用场景变化和“当晚、次日、返校后”等相对锚点；具体日期与钟点只在证据、期限或用户明确指定时保留。修复冲突时可删减无用刻度，不用更多时间数字圆场。

只输出完整修订后的正文，不输出标题、幕名、修改说明、自检报告或 Markdown。输出前自行核对本次要求与关联场景是否一致。

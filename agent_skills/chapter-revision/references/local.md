# 局部修订交付

一次处理本次明确要求，通读完整编号正文，只替换必要段落。允许在选中的情节增强范围内丰富段内内容，不为保持原句而放弃增强；无关段落与段间空白不改。

涉及时间线时，先还原事件顺序，再用最少的自然时间锚点修订。除非具体日期或钟点直接影响证据、期限或行动可行性，不新增精确时间；原稿中过密且无剧情作用的时刻可改成相对时间。不要为了证明连续性逐段报时。

只输出 JSON 补丁数组，每项包含 `id`（原段落编号）、`before`（逐字复制原完整段落）、`after`（修改后的完整段落）。不改动段落编号，不删除、添加或合并段落，`after` 不含换行；未修改的段落不返回。无需改动可返回 `[]`。需要重构场景或大幅增删段落时应使用整章模式，而不是扩大局部补丁权限。

# 故事蓝图

把长篇小说视为可调整的整体结构，而不是连续生成的孤立章节。先识别故事最终要抵达的变化，再设计阶段、主支线、里程碑和临近章节路线。

正文事实、未来规划、调整提案必须分层：

- 事实只来自已保存正文或摘要，并标注依据章节；摘要未提及不等于事情没有发生。
- 未来规划描述目标状态、结构作用与收束条件，不能伪装成已经发生的事件。
- 对已有蓝图的改变写入提案，说明改变了什么以及为什么；不静默改写锁定节点。

远期规划保持方向性，避免提前写死场景；临近章节可以规定必须发生的变化和章末状态，但分幕仍负责具体实现。故事线必须是人物、关系、目标、风险或局面的持续变化，不能把日期、档案、道具或单条线索独立包装成故事线。

每个阶段具有进入状态和退出状态；每条故事线具有当前状态、目标状态、下一压力、交汇点和收束条件；每个里程碑必须改变至少一条故事线并服务于阶段退出。章节路线图只安排结构职责，避免重复近期已经使用的场景功能。

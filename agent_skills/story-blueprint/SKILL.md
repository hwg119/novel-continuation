# 故事蓝图

把长篇小说视为可调整的整体结构，而不是连续生成的孤立章节。先识别故事最终要抵达的变化，再设计阶段、主支线、里程碑和临近章节路线。

主题是长期潜台词，不是逐章执行清单。把主题写成作品持续追问的价值问题和两种合理价值之间的张力；不要把答案写成角色必须完成的制度任务。章节应先有具体人物欲望、关系、行动与后果，主题只从选择和反差中自然显现。避免让角色频繁说出主题词，避免把连续章节设计成同一命题的案例演示。

总体骨架同时建立可轮换的叙事调色板，例如关系日常、探索神秘、行动意外、安静情绪或幽默缓冲。故事线应优先属于具体人物或关系，包含行动主体、私人欲望和独立矛盾；抽象社会议题只可作为背景交汇线。里程碑必须由人物选择或外部事件改变方向，不能是“依次展示所有群体”或“收集若干案例”的覆盖清单。

正文事实、未来规划、调整提案必须分层：

- 事实只来自已保存正文或摘要，并标注依据章节；摘要未提及不等于事情没有发生。
- 未来规划描述目标状态、结构作用与收束条件，不能伪装成已经发生的事件。
- 对已有蓝图的改变写入提案，说明改变了什么以及为什么；不静默改写锁定节点。

远期规划保持方向性，避免提前写死场景；临近章节规定人物、关系或局面需要发生的变化，但表层事件只是可调整的故事机会，除非用户明确锁定，否则不应代替分幕写死场景。故事线必须是人物、关系、目标、风险或局面的持续变化，不能把日期、档案、道具、单条线索或抽象议题独立包装成故事线。

每个阶段具有进入状态和退出状态；每条故事线具有当前状态、目标状态、下一压力、交汇点和收束条件；每个里程碑必须改变至少一条故事线并服务于阶段退出。章节路线图只安排结构职责和人物变化，避免重复近期已经使用的场景功能、主要地点、人物组合、互动方式和情绪质感。不能用给相似会议换不同 event_mode 的办法伪造多样性。

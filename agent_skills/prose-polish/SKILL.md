# 表达润色

“去 AI 味”在本任务中只表示改善读感，不能证明作者来源。通读后优先处理可互换人物的泛泛表达、重复解释、同质化对白和无作用的结尾总结，不按照词语黑名单、密度或评分指标改写。

先保留有效的具体细节、人物差异和题材语体，再精简冗余。允许有目的的心理描写、比喻、犹疑和重复，不把文风统一成极短句或白描。只修改确有收益的段落，没有收益输出 []，不凑修改数量。

## 不变项

所有事件与行动先后、人物身份关系、时间地点、关键物件、线索内容、事实确定程度和最终状态保持原样。不得新增主线、新证据、新认知或人物决定；不能为了更有张力把“可能”改成“确定”。保留原文信息，尤其引用文书、对白中的关键证词与有意的措辞区别。

仅修改表达，不执行用户附加要求中涉及剧情重构的内容。若表达问题只能靠改变情节解决，保留原文。作者的语体、口吻、称谓和固定译名继续有效。

## 输出补丁

输入是完整编号正文。只输出 JSON 数组，每项为 {"id":段落编号,"before":"逐字复制原段落","after":"润色后完整段落"}。after 不含换行，不增删、合并段落；未涉及段落不返回。程序验证原文逐字匹配后生成候选稿，不自动覆盖正文。
